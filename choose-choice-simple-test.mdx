# Simple Choose & Choice Components Test

This page tests the simplified Choose and Choice components that work with any build system.

**How it works:**
- Uses pure JavaScript with no React dependencies
- Components are initialized using HTML data attributes
- Selections persist across page refreshes using localStorage
- Compatible with Mintlify's build system

// Debug display
function updateDebug() {
  const debugEl = document.getElementById('debug-content');
  if (debugEl && window.choiceStateManager) {
    const state = window.choiceStateManager.getState();
    debugEl.innerHTML =
      'App Type: ' + (window.getChoiceValue('simple.app_type') || 'undefined') + '<br/>' +
      'Demo: ' + (window.getChoiceValue('simple.demo') || 'undefined') + '<br/>' +
      'All State: ' + JSON.stringify(state, null, 2).replace(/\\n/g, '<br/>').replace(/ /g, '&nbsp;');
  }
}

// Update debug info on state changes
window.addEventListener('choiceStateUpdate', updateDebug);

// Initial debug update
setTimeout(updateDebug, 100);
`}} />

## Testing Instructions

1. **Test Basic Choices**: Click the different app type options and verify that conditional content shows/hides correctly
2. **Test Button Trigger**: Select "Create new Box App" and click the blue button to test the trigger functionality
3. **Test Multi-Value**: Verify that the security notice appears when you select appropriate options
4. **Test Unset State**: The demo section should show default text until you make a choice
5. **Test Persistence**: Navigate to another page and come back - your choices should be remembered
6. **Test Grid Layout**: Verify that the Grid displays items in the correct number of columns
7. **Test Visual Feedback**: Selected options should have thicker borders, scaling, and color changes

The debug information at the bottom shows the current state for testing purposes.

This simplified implementation should work reliably with Mintlify's build system without React or module dependencies.
