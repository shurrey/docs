# Choose & Choice Components Test

This page tests the interactive Choose and Choice components to ensure they work correctly with existing guide patterns.

**How it works:**
- The **Choose** components below are always visible and let you select options
- The **Choice** components show/hide content based on your selections
- Content is hidden by default until you make a choice (this is the expected behavior)
- Selections persist across page refreshes using localStorage

## Testing Instructions

1. **Test Basic Choices**: Click the different app type options and verify that the conditional content shows/hides correctly
2. **Test Trigger/Observe**: Select "Create new Box App" and click the trigger button to test the Observe component
3. **Test Multi-Value**: Verify that the security notice appears when you select either "create_new", "use_existing", or trigger "clicked"
4. **Test Unset State**: The demo section should show default text until you make a choice
5. **Test Persistence**: Navigate to another page and come back - your choices should be remembered
6. **Test Grid Layout**: Verify that the Grid component displays items in the correct number of columns

The debug components at the bottom show the current state for testing purposes.
