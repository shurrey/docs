# Box開発者ガイドへようこそ

このドキュメントサイトは、Box Platformを使用してアプリケーションを構築するための包括的なリソースです。

## 🚀 はじめに

Box Platformは、コンテンツ管理、コラボレーション、セキュリティ機能を提供する強力なクラウドプラットフォームです。

### 主な機能

- **ファイル管理**: アップロード、ダウンロード、プレビュー
- **コラボレーション**: 共有、コメント、タスク管理
- **セキュリティ**: アクセス制御、暗号化、監査
- **Box AI**: AI搭載のコンテンツ分析と質問応答

## 📚 ドキュメントの構成

### アプリケーション
- アプリタイプの選択
- プラットフォームアプリ
- 制限付きアクセスアプリ
- カスタムスキル

### 認証
- OAuth 2.0
- JWT（サーバー認証）
- クライアント認証情報
- アプリトークン

### Box AI
- クイックスタート
- AIエージェント
- AIモデル
- AIチュートリアル

### 開発者ツール
- CLI（コマンドラインインターフェース）
- SDK（ソフトウェア開発キット）
- Postman
- Salesforceツールキット

## 🎯 次のステップ

1. [Box開発者コンソール](https://account.box.com/developers/console)でアプリを作成
2. 認証方法を選択
3. 最初のAPI呼び出しを実行
4. Box UI Elementsを統合
